🥷🏻 **Інструменти, які допоможуть у проведенні цифрових розслідувань**

[DFIR Toolkit](https://github.com/dfir-dd/dfir-toolkit) - інструменти CLI (інструменти командного рядка) для криміналістичного дослідження артефактів Windows. Ці інструменти допомагають аналізувати дані з різних джерел, таких як реєстр, журнали подій, файлова система та дампи пам'яті. 

[Analisi Digital Forense](https://github.com/CScorza/Analisi-Digital-Forense) - криміналістичний цифровий аналіз. Криміналістика Windows. Криміналістика метаданих. Криміналістика MacOs. Відновлення даних, аналітика програмного забезпечення тощо.

[CyberForensics Tools Hub](https://osint-toolkit-central-main.vercel.app/) - комплексні інструменти для цифрових розслідувань в одній централізованій платформі. Для перевірки IMEI та IP-адреси. Інструменти для аналізу криптовалют. Інструментарій для аналізу зображень/відео та роботи з інтернет-архівами. Аналіз підозрілих файлів тощо.

[Telegram Tool](https://github.com/Jieyab89/OSINT-Cheat-sheet?#telegram-tool) - інструменти для аналізу Телеграм. Пошук за назвою каналу, іменем користувача, назвою ботів тощо. З цікавого, інструменти[ перевірки ботів](https://matkap.cti.monster/) на наявність шкідливого ПЗ, списки шахрайських акаунтів в Телеграм, Телеграм архіви.
