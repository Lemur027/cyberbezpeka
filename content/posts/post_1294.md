👥 **Інструменти для роботи з аудіофайлами
**
[Beatsync](https://www.beatsync.gg/) - високоточний веб-плеєр для відтворення аудіо одночасно на декількох пристроях. Синхронізація відтворення до мілісекунд. Не потребує встановлення, працює на всіх пристроях, найкраще в Chrome. Створюєте кімнату, автоматично генерується ID, який і буде допуском для інших пристроїв. Дозволяє регулювати просторове відтворення та гучність окремо для кожного з пристроїв (функція Spatial). По суті, можна зробити акустичну систему зі всіх своїх девайсів.

[Wavacity](https://wavacity.com/) - редактор аудіо від Audacity, який працює прямо в браузері (для десктопів). Простий інтерфейс, великий набір ефектів та інструментів для роботи з аудіофайлами. Безкоштовний. Підтримує велику кількість різних бібліотек: TwoLAME, Vamp, SoundTouch, Expat тощо.

[Auphonic](https://auphonic.com/) - веб-інструмент для пост-продакшну аудіо для досягнення професійної якості звуку. Він автоматично вирівнює гучність, зменшує шум, забирає ехо, видаляє дихання, навіть присутня функція видалення слів паразитів (більше для англомовних записів) та моментів мовчання. Від вас потрібно лише завантажити аудіо/відео та обрати режим обробки (з вище перелічених). Дві години безкоштовної генерації на місяць. Реально непогано працює.
