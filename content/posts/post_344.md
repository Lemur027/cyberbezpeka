🇺🇦 **Підбірка сервісів для редагування зображень

**[imgeditor](https://imgcreator.zmo.ai/ai-designer) - фотошоп на основі штучного інтелекту, виділяєте область та вказуєте, що потрібно з нею зробити.

[watermarkremover](https://www.watermarkremover.io/), [theinpaint](https://theinpaint.com/) - для видалення водяних знаків на зображеннях.

[ojoy](https://ojoy.zaps.dev/), [letsenhance](https://letsenhance.io/boost) - для покращення якості ваших зображень.

[clipdrop](https://clipdrop.co/cleanup), [ hama](https://www.hama.app/),[ cleanup ](https://cleanup.pictures/)- для видалення непотрібних об'єктів на зображенні (людей, предметів, тощо).

[palette](https://palette.fm/) - кольоризація чорно-білих фотографій.

[neural.love](https://neural.love/portraits) - портрети у високій якості, для коректної роботи зображення повинно бути чітким, без засвітів, затінень, головних уборів, пошкоджень та шумів.

Більше сервісів в цій [підбірці](/posts/post_3450/).
