🗽 **Деякі цікаві сервіси та фішки для Windows та Linux. Частина 3**

[iTop Easy Desktop](https://apps.microsoft.com/detail/xpfcjvzv10x2wv?hl=uk-ua&gl=UA) - програма для організації робочого столу у Windows. Якщо ваш робочий стіл завалений іконками, теки та файлами. Вона створює так звані портали папок, далі автоматично сортує всі елементи роб. столу за трьома категоріями: програми, папки, файли та документи. Кожен портал кастамізується як вам зручно. Доступні також різного роду віджети. Безкоштовно. Можна завантажити [через Steam.](https://store.steampowered.com/app/2620310/iTop_Easy_Desktop/)

[Linux command library](https://linuxcommandlibrary.com/) - найбільша бібліотека команд і підказок для ОС Linux. Досить зручне сортування. Є як веб-версія, так і [додаток для android.](https://play.google.com/store/apps/details?id=com.inspiredandroid.linuxcommandbibliotheca) Наразі додаток містить 6056 сторінок з інструкціями, 22+ базові категорії та безліч загальних порад щодо роботи з терміналом. Він працює офлайн, не потребує підключення до інтернету і не містить програмного забезпечення для відстеження.

[MovaFlag](https://github.com/Z-beam/MovaFlag/releases/tag/1.0.0) - open source програма⁠ для Windows від українського розробника. Єдина її функція, постійно нагадувати, яка мова зараз ввімкнена на вашій клавіатурі. Біля курсора просто з'являється прапорець з відповідною мовою.

[Unlock IT](https://emcosoftware.com/unlock-it)** **[-](https://lockhunter.com/) безкоштовний інструмент для видалення файлів, заблокованих якимись процесами, про які вам навіть невідомо. Показує процеси, що блокують файл або папку. Дозволяє розблокувати, видалити, скопіювати або перейменувати заблокований файл. Корисний для боротьби зі шкідливими програмами, які блокують файли без причини.

**Швидке оновлення програм у Windows.** Прописуємо в терміналі команду «`winget upgrade`», ця команда просканує та продемонструє всі доступні оновлення для ваших програм. Щоб запустити процес оновлення одразу усіх знайдених програм, прописуємо «`winget upgrade --all`».  Також у [цій статті](https://learn.microsoft.com/en-us/windows/package-manager/winget/upgrade) детальний туторіал по використанню цієї команди.
