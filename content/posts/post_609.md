🧐 **Деякі цікаві інструменти для аналізу та перевірки

**[creationdatebot](https://t.me/creationdatebot)  - показує ID акаунта, та приблизну дату його реєстрації (не завжди точно).

@onspectorbot - український бот для перевірки телеграм акаунтів на шахрайство. Актуально для при роботі з телеграм каналами. Також показує ID акаунта (не завжди працює).

[Bitcoin Transaction Visualizer](https://orion.ninja/), [Breadcrumbs](https://www.breadcrumbs.app/) - інструменти для відслідковування транзакцій криптовалюти та їхньої візуалізації.

[Sucuri](https://sitecheck.sucuri.net/), [SafeWeb](https://safeweb.norton.com/) - сервіси для перевірки безпечності сайтів. Просто введіть адресу сайта, який вас цікавить.
