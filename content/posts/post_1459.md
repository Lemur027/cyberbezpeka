👥 **Інструменти для навчання та роботи з текстом**

[Voxdeck](https://www.voxdeck.ai/) — новий інструмент для створення презентацій. Якість формування, текстова та візуальна частини на хорошому рівні, матеріали підбирає актуальні. Безкоштовно дозволяє створити одну презентацію (до восьми слайдів). Презентації тут анімовані, навіть доступне озвучення створених презентацій; це виглядає ніби ви дивитесь зі сторони, як хтось розповідає про вашу презентацію. Правда, озвучення лише англійською мовою, тому це не дуже актуально. **Також інші інструменти для створення та генерування презентацій залишав тут: **/posts/post_3450/

[Hyperlink](https://hyperlink.nexa.ai/) — програма для завантаження книг, статей та інших матеріалів для спілкування з ними. Доступний режим офлайн, повністю безкоштовна та без жодних лімітів на обсяги завантажуваних матеріалів. Також заявляють про високий рівень конфіденційності. Доступна для операційних систем Windows та macOS. Присутній режим розумного пошуку файлів: якщо не пам'ятаєте назву — просто опишіть, про що там йдеться. Щось по типу офлайн Perplexity для ваших файлів. Пошук, аналіз, підсумок. Правда, потрібна мінімум 8 ГБ відеокарта або 32 ГБ оперативної пам'яті.

[Handwrite](https://www.handwriteai.co.in/)** **— безкоштовно перетворює друкований текст у рукописний. Один шрифт для кирилиці. Дозволяє змінювати розмір тексту. [Handtext](https://handtextai.com/)** **— шрифти більш схожі на "лікарські", тобто виглядає це все більш природньо. Дозволяє змінити задній фон, безкоштовно 5 сторінок, лише в лінійку або без розміток. [Exttohandwriting](https://texttohandwritingai.com/) — генерує непогано задній фон, доступні режими: лінійка та без розміток. Також накладення ефектів: тіні (імітація фото) або сканер. Шрифт Caveat, як у першого. Безкоштовний. Щодо латиниці, вибір шрифтів величезний у всіх згаданих сервісах. [Penwrite](https://penwrite.oas.in.ua/)** **— український аналог. Вибір шрифтів, фонів, зошитів, налаштування камери. Всього більше і краще ніж у попередників. Але лише 5 безкоштовних спроб.
