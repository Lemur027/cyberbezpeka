🥷🏻 **Перевірка GitHub-репозиторіїв, браузерних розширень та файлів для Node.js**

[ExtSentry](https://extsentry.github.io/) — список браузерних розширень, які були скомпрометовані використанням шкідливого програмного забезпечення або потенційно небажаних програм (PUP), зараженням системи, шахрайством, викраденням облікових даних, обходом систем захисту. Тобто розширення, які потрібно негайно виявити та видалити. Багато таких розширень діють як «сплячі агенти» — протягом місяців або років поводяться як звичайні, а потім починають викрадати дані, перехоплювати пошукові запити та збирати інформацію. Також є окремий список «чутливих» розширень: криптогаманці та менеджери паролів, які самі по собі не є шкідливими, але на які часто націлені програми-викрадачі.

[Pompelmi](https://github.com/pompelmi/pompelmi) — інструмент перевірки файлів на віруси або підозрілий вміст ще до їхнього збереження на сервері. Наприклад, у вас є сайт, куди користувачі можуть завантажувати файли (фото, PDF, архіви). Він перевіряє файли ще в процесі завантаження, перш ніж вони потраплять до сховища. Перевіряє тип файлу (чи не підроблений), його розмір, аналізує вміст (наприклад, наявність макросів або шкідливого коду), зловживання архівними форматами, глибоку інспекцію ZIP-архівів. Якщо щось не так, файл блокується. Без хмарного API, без фонового процесу, без необхідності виведення даних. Сумісність: Express, Next.js, NestJS, Fastify, Koa.

[OSM Eye](https://github.com/Ner-Kun/osm_eye) — GitHub під наглядом. Перевіряйте репозиторії на GitHub на наявність шкідливого коду. Цей інструмент автоматично звіряє репозиторії, які ви переглядаєте, з базою загроз OpenSourceMalware. Якщо проект підозрілий, відразу показує плашку. Репозиторії скануються автоматично одразу при відкритті сторінки. Фільтрація за рівнем небезпеки (Low, Medium, High, Critical). Доступне у форматі розширення для браузерів Chrome, Edge, Brave тощо. Інструмент щойно вийшов, його ще немає в офіційних магазинах, але можна встановити вручну.[ Український](https://t.me/ner_kun_off/379) розробник.
