😑 **Фреймворки для створення телеграм-ботів та нейронних мереж 
**
[Aiogram](https://aiogram.dev/) - бібліотека для створення телеграм ботів від українського розробника. Підійде і для ботів з великою кількістю користувачів. Повністю асинхронний фреймворк для Telegram Bot API, написаний на Python 3.8+ з використанням asyncio та aiohttp.

[TensorFlow](https://www.tensorflow.org/) - фреймворк від Google для програмування штучних нейронних мереж (ML-моделей) для настільних, мобільних, веб- та хмарних пристроїв. Акцентований більше під комерційні розробки. Відкритий вихідний код. 

[PyTorch](https://pytorch.org/) - фреймворк для програмування штучних нейронних мереж з відкритим вихідним кодом від учасників Linux Foundation. Акцентований під наукові, дослідницькі проекти. Присутній [репозиторій](https://github.com/pytorch/pytorch) з детальним розбором роботи фреймворку. 

[Playground TensorFlow](https://playground.tensorflow.org/) - інтерактивна візуалізація нейронних мереж. Тут можна побудувати нейромережу для класифікації даних, побудувати її структуру, додавати шари, нейрони, обирати тип/швидкість навчання (коло, гаус, спіраль) тощо.  А також наочно змоделювати сам процес навчання.

[The AI Engineer’s Handbook](https://handbook.exemplar.dev/) - довідник інженера зі штучного інтелекту. LLM, Prompt Engineering, векторні бази даних, ембеддинги, RAG, CAG, ШІ агенти, тулзи для розробників, безпека, захист та етика ШІ.

Більшість ресурсів знайшов на YouTube-каналі [HackWhiz (Хеквіз)](https://www.youtube.com/@hackwhizzz), автор якого програмує різні цікаві проекти, пов'язані з нейромережами.
