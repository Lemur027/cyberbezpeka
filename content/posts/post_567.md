💆‍♂️ **Інструменти для роботи з зображеннями. Частина 2

**[Restorephotos](https://www.restorephotos.io/restore)** **- для відновлення обличчя для старих та розмитих фото (5 генерацій на день).

[Blur background](https://www.cutout.pro/blur-background) - інструмент на базі штучного інтелекту, для розумного розмиття фону (блюру) на фотографії.

[Clipdrop](https://clipdrop.co/relight), [Relight](https://relight.oblio.io/#) - для зміни освітлення на фото. Досить непогано, порівняно з іншими сервісами.

[WatermarkRemover ](https://www.watermarkremover.io/)- інструмент для видалення водяних знаків на фото.

[Canva AI](https://www.canva.com/) - для видалення та заміни об'єктів на фото. На сайті обираємо "соцмережі - редагування фото - магічне редагування".
