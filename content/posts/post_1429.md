👥** Цікаві open source рішення для систем Android та Linux
**
[Offline Translator](https://f-droid.org/packages/dev.davidv.translator/)** **— безкоштовний додаток-перекладач, який використовує моделі перекладу Firefox для офлайн-перекладу на пристроях Android. Виконує переклад тексту та зображень (OCR) повністю в автономному режимі, використовуючи попередньо завантажені мовні пакети на пристрої. Ніяких запитів на зовнішні сервери. Доступно 42 мови, зокрема українська. Відкритий [вихідний код](https://github.com/DavidVentura/firefox-translator) на GitHub.

[QUIK](https://github.com/octoshrimpy/quik)** **— відкрита альтернатива базовому додатку для обміну повідомленнями на Android. Присутній український інтерфейс. Можливості: заплановані повідомлення, резервне копіювання повідомлень, інтегрована в додаток функція перетворення мовлення в текст і тексту в мовлення, блокування та архівування повідомлень, голосові повідомлення, вкладення будь-якого типу файлів, відкладена відправка тощо.

[Waydroid ](https://waydro.id/)— дозволяє запускати повноцінну систему Android "у контейнері" на звичайній системі GNU/Linux, такій як Ubuntu або Debian. Він переносить усі ваші програми прямо на робочий стіл, де вони працюють поряд із вашими програмами для Linux. Використовуваний образ наразі базується на Android 13. GitHub [репозиторій](https://github.com/waydroid/waydroid) проєкту.  

[WinBoat](https://github.com/TibixDev/winboat) — дозволяє запускати програми Windows на Linux за допомогою контейнерного підходу. Windows працює як віртуальна машина всередині контейнера Docker. Інтуїтивно зрозумілий інтерес з автоматичною інсталяцією. Запускає будь-які програми, якщо ці програми працюють на Windows. Також дозволяє без зайвих бубнів обмінюватися файлами між двома системами.
