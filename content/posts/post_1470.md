👥 **Програми для Windows, MacOS, Linux та LLM-додатки**

[Definitive opensource](https://github.com/mustbeperfect/definitive-opensource) — величезний репозиторій відбірних open source програм для Windows, MacOS та Linux. Автор називає цей список єдиним централізованим місцем для найкращих проектів з відкритим ПЗ, які характеризуються міцною базою користувачів, довготривалістю та загальною якістю продукту. Список не заради списку, справді багато корисних програм. Мінімалістичний інтерфейс, сортування за операційними системами або напрямками (приватність, безпека, текст, термінал, медіа, ШІ тощо). Присутні теги, які відображають виявлені вразливості та критичні баги конкретних програм, їх покинутість розробниками, залежність від корпорацій тощо.

[Awesome Windows](https://github.com/0PandaDEV/awesome-windows) — ретельно підібраний перелік інструментів та програм для Windows 10/11. Великий список, деталізоване сортування: файлові менеджери, аудіо, графіка, термінал, офіс, VPN/Proxy, безпека, робота з текстом, віртуальні машини, програми віддаленого робочого столу, системні утиліти по типу програми для очищення системи BleachBit або WizTree для швидкого аналізу дискового простору та інші категорії. Загалом знайшов багато перевірених рішень, підбірка справді ретельна, всі посилання тільки на офіційні версії програм, ніяких сумнівних прямих завантажень.

[Awesome LLM Apps](https://github.com/Shubhamsaboo/awesome-llm-apps) — кураторський список найкращих додатків LLM, створених за допомогою RAG, AI-агентів, мультиагентних команд, MCP, голосових агентів тощо. У цьому репозиторії представлені додатки LLM, які використовують моделі від OpenAI, Anthropic, Google, xAI та моделі з відкритим кодом, такі як Qwen або Llama, які можна запускати локально на своєму комп'ютері. Допоможе знайти практичні та креативні способи застосування LLM у різних сферах, від репозиторіїв коду до поштових скриньок тощо.
