👥 **Розпізнавання об'єктів, безпечний перегляд та світчери
**
[Deep Data Space](https://deepdataspace.com/home) - інтерактивну ШІ модель на базі T-Rex2, призначена для виявлення та підрахунку об'єктів на відкритій місцевості. Досить непогано працює з детектом об'єктів на зображеннях. Приклад роботи на відео.

[Dangerzone](https://dangerzone.rocks/) - програма конвертує потенційно небезпечні PDF-файли, офісні документи або зображення на їхні безпечні для перегляду версії. Для роботи потрібен Docker. Наявні версії для всіх популярних ОС. Працює за принципами контейнерів, детально про його принцип роботи ви можете [прочитати тут](https://dangerzone.rocks/about.html).

[Lang switcher](https://apps.apple.com/ua/app/lang-switcher-autoswitch/id1597566195?mt=12) - світчер для користувачів Mac OS для швидкої заміни тексту, випадково набраного іншою мовою. Для користувачів Windows підійде [Faine switcher](https://faineswitcher.com/). Обидві українські розробки.
