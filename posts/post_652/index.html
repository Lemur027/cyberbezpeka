🗽**Інструменти для роботи з відео

**Jitter - робить шаблонну, але гарну графіку для ваших відео. Підійде для простих завдань пов’язаних з моушн графікою. Працює з Фігмою, але в безкоштовній версії тільки 720 з водяним знаком.

Kapwing - онлайн редактор відео. Простий та зрозумілий у користуванні, також наявні автоматизовані субтитри, підтримують українську мову. Є місячні ліміти.

Vmake - покращує якість ваших відео. Робить це досить непогано, завантажити можна в хорошій якості без водяних знаків. Наявні ліміти на відео тривалістю більше 5 секунд.

Leiapix - нейромережа дозволяє перетворювати звичайні 2D-зображення на їхні анімовані версії (3D-ефект). Є можливість безкоштовно завантажити без водяних знаків.

Wonder studio - ШІ для заміни акторів на CG-персонажів. Приклад його роботи ви бачите на відео. Повністю платний.я

Davinci Resolve - повноцінний відеоредактор, але потребує встановлення і тільки для ПК. Безкоштовного функціоналу цілком вистачає для більшості задач.
